# Cloud Advisory Group

Static single-page website for Cloud Advisory Group, an Australian boutique consultancy for AWS, Azure, Google Cloud, Salesforce, APIs and Claude advisory.

Plain HTML, CSS and JavaScript. No build step. Served by GitHub Pages from `main`.

- Change the contact address in `script.js` (`CONTACT_EMAIL`).
- Preview locally: `python3 -m http.server` then open http://localhost:8000
